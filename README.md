# Working Out
## A Donny Benét Themed Workout Tracker
[Hitting the gym every night and day](https://www.youtube.com/watch?v=qh74fm-FGFo)

## Version 0.1

* Navigation (ugly) with central Add Button
* Exercise List
	* Search Exercises
	* Add with Name and Exercise Modality
		* Exercises have Exercise Modality for Workouts (RepsWeight, Reps, etc.)
	* Delete Exercise
* Workout List
	* Workouts have Title, Date and Duration and Active or not
	* Add with Title and Date
* Workout Page
	* Workouts is List of Exercises
	* Every Exercise Block is list of Sets

## Version 0.2

* Exercise Page

	* Weekly volume
